Property branches

Each row adds a top-level folder listing every value of that property. Use Jellyfin's own names (not case-sensitive), e.g. studios, genres, productionYear, person.director, video.codec, audio.language. Pick a suggestion or type any item property; tag is covered by Tags. Names that match nothing show nothing.

Channels

Jellyfin shows each channel as its own entry. By default there is one, the Tag Browser. You can turn it off, and promote any branch to a channel of its own.
Off hides the main channel. Channels promoted below stay.

Separate channels

Each row turns one branch into its own channel (up to 10). Branch is a branch or folder as shown in the tree, using the tag separator for levels: dance opens a channel showing what is under the dance tag (so dance: zouk appears as zouk), dance: zouk opens at that folder, and a property branch uses its shown name, e.g. Studios. A promoted branch is moved, not copied: it leaves the main channel, so each video is listed in one place. Renaming a channel creates a new one, and the watched state of its videos starts again. Changes apply when you save.
